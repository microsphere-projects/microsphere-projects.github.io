Design principles

Six engineering principles running through all 32 sub-projects.

A layered foundation, bottom up

microsphere-java supplies framework-free building blocks — strings, reflection, type conversion, event dispatch — shared by every layer with identical semantics.

Runtime dynamism without restarts

Configuration changes drive Feign hot-refresh, property source reloads and live i18n message updates — no application restart required.

Non-intrusive observability

SQL, Redis and Feign call paths feed Micrometer and Prometheus through interception pipelines — not a single line of business code changes.

Resilience built for production

Sentinel and Resilience4j share one programming model across web, database and cache — flow control and circuit breaking adopted incrementally.

Rigorous engineering governance

One parent POM covers five Java TLS versions; six Maven profiles manage build, signing, coverage and release.

Long-lifecycle compatibility

main and 1.x lines run in parallel, carrying one codebase across Spring Boot 2.x–4.x and Spring Cloud Hoxton–2025.x.

Overview

Microsphere in one minute

Microsphere Projects is an open-source organisation of 36 GitHub repositories that provides layered enhancements for the Java and Spring ecosystem. It is not a single framework but a composable capability matrix — use the utility library alone, add Spring Cloud extensions for restart-free Feign refresh, or stack observability, internationalisation and multi-active routing on top.
