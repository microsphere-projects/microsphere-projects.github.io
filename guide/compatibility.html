Compatibility Matrix ​

Microsphere maintains two release lines: main targets the current framework generation, 1.x serves existing systems. Both offer the same feature set but compile against different baselines.

Do not mix lines

Never include both 0.2.x and 0.1.x modules in one application — it causes classpath conflicts and unpredictable auto-configuration behaviour.

JDK support ​

The microsphere-build parent POM covers Java 8 / 11 / 17 / 21 / 25, but individual sub-projects have their own baselines:

BaselineProjects
Java 8+microsphere-java, microsphere-logging, microsphere-java-enterprise, microsphere-test, microsphere-tools
Java 17+microsphere-spring, microsphere-spring-boot, microsphere-spring-cloud, microsphere-i18n, microsphere-gateway, microsphere-hibernate (0.2.x), microsphere-multiactive

CI verifies the full matrix on Java 17, 21 and 25 against the Spring Cloud 2022 / 2023 / 2024 / 2025 profiles.

Switching Spring Cloud versions ​

The main branch builds against Spring Cloud 2025.0.x by default. To build or test against an older generation, activate the corresponding Maven profile:

bash
./mvnw verify -P spring-cloud-2022
./mvnw verify -P spring-cloud-2023
./mvnw verify -P spring-cloud-2024
