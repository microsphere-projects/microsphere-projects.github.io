# 2026-10-23

## 构建 Microsphere Projects 官方站点

为 https://github.com/microsphere-projects 组织重做官方网站。

**技术选型**：VitePress 1.6.4（Markdown 驱动 + 静态站点，符合"各级网页用 Markdown 独立存储"的要求）。

**交付内容**：
- 40 个页面：首页、架构大图、生态全景、社区、3 篇指南、32 个子项目独立单页、项目总览
- 子项目按五层架构归类：L0 工程基座(2) / L1 运行时基座(7) / L2 框架扩展(3) / L3 生态集成(12) / L4 横向能力(8)
- 架构大图页集成可交互分层图 + 按能力域横切汇总的特性矩阵 + SVG 调用链路图
- 自建设计系统：紫青渐变品牌色、玻璃拟态卡片、网格光晕 hero，支持明暗主题

**数据来源**：全部子项目特性取自各仓库 README（经 GitHub API 抓取，`raw.githubusercontent.com` 在本机不通，需走 API + base64 解码）。

**工程约定**：
- `tools/data.py` 是 32 个子项目的权威数据源，`tools/gen.py` 生成 `docs/projects/*.md`、sidebar.mjs、projects.json
- 构建命令必须是 `vitepress build docs`（不能省 `docs`），否则 root 推断为工作区根导致 108 死链
- CLI 默认 root 不会自动识别 `docs/.vitepress`，已在 package.json scripts 中显式指定

**踩过的坑**（重要）：
1. Markdown 正文里的裸 `<version>` 会被 Vue 当 HTML 标签解析，报 "Element is missing end tag"。已加 `safe()` 转义为 `` `&lt;version&gt;` ``
2. `srcDir: '.'` 会把扫描根指向工作区根，应删除让其自动推断
3. cleanUrls 下内部链接不能带 `.md` 后缀
4. SVG 的 `fill="var(--x)"` 不生效，须写成 `style="fill:var(--x)"`
