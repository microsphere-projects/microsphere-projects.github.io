设计取向

六条贯穿全部 32 个子项目的工程原则。

自下而上的分层地基

microsphere-java 提供字符串、反射、类型转换、事件分发等零框架依赖的基础能力，全生态共享同一套语义。

免重启的运行时动态性

配置变更驱动 Feign 组件热刷新、属性源自动重载、i18n 消息在线更新——变更生效不依赖应用重启。

非侵入的可观测性

SQL、Redis、Feign 调用链通过拦截管道接入 Micrometer 与 Prometheus，无需改动一行业务代码。

面向生产的韧性

Sentinel 与 Resilience4j 以统一编程模型覆盖 Web、数据库与缓存，流控与熔断渐进式接入。

严谨的工程治理

统一父 POM 覆盖 Java 8–25 五个 TLS 版本，六套 Maven profile 管理构建、签名、覆盖率与发布。

长周期版本兼容

main 与 1.x 双线并行，同一套代码横跨 Spring Boot 2.x–4.x、Spring Cloud Hoxton–2025.x。

一分钟了解 Microsphere ​

Microsphere Projects 是一个由 36 个 GitHub 仓库组成的开源组织，围绕 Java 与 Spring 生态提供分层增强。 它不是一个单一框架，而是一套可以按需组合的能力矩阵：你可以只用最底部的 microsphere-java 作为工具库， 也可以引入 Spring Cloud 增强实现免重启的 Feign 配置刷新，再往上叠加可观测性、国际化与多活路由。

所有项目共享同一套工程约定：

  • 统一 Group ID — io.github.microsphere-projects
  • 统一 BOM 治理 — 每个子项目都提供 *-dependencies 模块，导入一次即可对齐全部版本
  • 统一构建口径 — microsphere-build 父 POM 覆盖 Java 8 / 11 / 17 / 21 / 25
  • 双版本线 — main 面向新一代（Spring Boot 3/4、Spring Cloud 2022–2025），1.x 面向存量（Spring Boot 2、Hoxton–2021）
