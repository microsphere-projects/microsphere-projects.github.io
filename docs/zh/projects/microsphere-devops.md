## 它解决什么问题

承载 Microsphere 生态的 DevOps 能力，覆盖构建、发布与环境管理等工程效能环节，并配套独立的 UI 项目。

## 核心特性

- **工程效能** — 支撑生态的持续集成与交付流程。
- **配套 UI** — 由 microsphere-devops-ui（TypeScript）提供可视化界面。

## 模块构成

| 模块 | |
|------|------|
| `microsphere-devops` | DevOps 脚本与配置 |
| `microsphere-devops-ui` | TypeScript 编写的 DevOps UI |

## 环境要求

| | |
|------|------|
| Node | 18+（devops-ui） |
